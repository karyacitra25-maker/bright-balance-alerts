# Vibrant Balance

Saya ingin kamu menambahkan warna pada halaman saldo begitu pun dengan yang lain saya ingin lebih berwarna tapi tetap mempertahankan latar belakang yang hitam,

Lalu saya juga ingin setiap pengguna mendapatkan notifikasi setiap saldo masuk dan setiap dan yang mendaftar melalui link referral mereka
